# Emoji target artwork attribution

The embedded target image in this neural cellular automaton is derived from
Google's Noto Emoji **Face with tears of joy** artwork (U+1F602, 😂).
The target artwork is credited to Google; training the model does not imply
authorship of the target artwork.

- Source repository: <https://github.com/googlefonts/noto-emoji>
- Pinned revision: `e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e`
- Original PNG: <https://raw.githubusercontent.com/googlefonts/noto-emoji/e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e/2D/png/128/emoji_u1f602.png>
- Recorded original PNG SHA-256: `15952ae860a14f39726198bc3d0ed948730d8fdde5afaee488140b0f76ee566b`
- Recorded acquisition time: `2026-10-17T17:05:52.467332+00:00`

The demo contains derived embedded pixel data used as its target, along with
trained model weights; it does not fetch the PNG at runtime.

The pinned upstream README states that tools and most image resources are
under Apache License 2.0. A copy of that license is supplied in
`LICENSE-APACHE-2.0.txt`. The same pinned revision's root `LICENSE` contains
the SIL Open Font License 1.1 and the notice `Copyright 2013 Google LLC`.
That upstream file is preserved unmodified in `LICENSE-NOTO-UPSTREAM.txt`,
and its text is also retained in `demo.js`. The upstream README is preserved
in `README-NOTO-UPSTREAM.md` so the differing image and font license statements
remain visible. The font license is not presented as a replacement license
for the PNG artwork.

These notices concern the external target artwork and do not relicense the
blog text, demo implementation, or trained model.
