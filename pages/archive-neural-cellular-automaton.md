<p>Each cell in this neural cellular automaton stores 16 values, called channels. A neural network acts as the local rule, updating the cells in discrete time steps so that a larger pattern can form. I reproduced <a href="https://distill.pub/2020/growing-ca/">the original paper</a> on a repurposed old laptop, using a different loss function.</p>

<p>Try damaging the pattern in the <a href="https://sjaakiechen.github.io/personal-blog/assets/evidence/demos/joy-checkpoint-5850-live/index.html?load=auto">regeneration demo</a>: click or drag across the live grid to erase cells, then watch how it responds. Double-click to add a seed, or use Reset to start again.</p>
