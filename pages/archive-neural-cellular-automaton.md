<p>Due to my long interest in consciousness, I tried reproducing <a href="https://distill.pub/2020/growing-ca/">this paper</a> using a repurposed old laptop. The paper was about how to create <a href="https://sjaakiechen.github.io/personal-blog/assets/evidence/demos/joy-checkpoint-5850-live/index.html?load=auto">robust structures</a> using only local rules and discrete time evolution (think of Conway's Game of Life).</p>
<p>I assigned 16 channels to each grid and trained a neural network to act as the local rule for each grid. I chose a different loss function and did reproduce the paper.</p>
