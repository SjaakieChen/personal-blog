<h2>Pre-alignment</h2>
<p>To know where the ball lens is relative to the chip, we need an image of the ball, the chip and a reference scale. But to move into position to take that image, we first need to be sure we are not going to hit anything. To know that, we need the picture. It is a chicken-and-egg problem.</p>
<p>This is my <a href="https://www.youtube.com/watch?v=B5ln2s0bnAY">pre-alignment procedure</a>: vision with cascading precision, which resolves that problem and always works.</p>
